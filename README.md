# almaham-3 — الالتقاط الذكي وقراءة عداد الكهرباء (تطبيق تجريبي)

تطبيق تجريبي منفصل (prototype): القارئ يوجّه الكاميرا داخل التطبيق ويضغط ← قص تلقائي للعداد ← محرك على الجهاز
(بدون إنترنت) يقرأ رقم الشاشة ← الرقم يتعبّى في خانة «القراءة الحالية» مع تحقق بالألوان. لو نجح، ينتقل الكود
للمشروع الرئيسي [`moain2026/almaham-2`](https://github.com/moain2026/almaham-2).

> **ابدأ من:** [`STATUS.md`](STATUS.md) (وين وصلنا الآن) ← [`AGENTS.md`](AGENTS.md) (القواعد والأوامر)
> ← [`docs/brief/`](docs/brief/) (المهمة الأصلية كما سلّمها المالك).

## الحالة باختصار (2026-10-18)
- **المرحلة:** البحث والقرار + تدريب المحرك. **التطبيق نفسه لم يُكتب بعد** (`app/` غير موجود).
- **أفضل محرك جاهز:** نموذج الـ ERP الحالي 17/46 (37%) — رخصته AGPL فممنوع في المنتج.
- **محركنا SegReader:** 15/46 (33%) على قصّ مثالي للسطر، بعد 4000 خطوة تدريب اصطناعي. **الهدف ≥95%.**
- كل الأرقام مقاسة على CPU السندبوكس وليس جوال. التفاصيل: [`docs/research/benchmark-summary.md`](docs/research/benchmark-summary.md).

## خريطة المستودع
| المسار | المحتوى |
|---|---|
| `STATUS.md` | الحالة الآن، خارطة الطريق، المعطّل، التالي |
| `AGENTS.md` / `CLAUDE.md` | تعليمات أي وكيل/مطوّر يكمل الشغل |
| `LESSONS.md` | كل مشكلة/خطأ صار وسببه وكيف نمنعه |
| `CHANGELOG.md` | سجل التغييرات |
| `docs/brief/` | الشرح + البرومت + البحوثات + صور التصميم (المصدر الأصلي للمتطلبات) |
| `docs/requirements/` | المتطلبات بصيغة EARS ومعايير القبول |
| `docs/adr/` | القرارات المعمارية وأسبابها |
| `docs/design/` | تصميم الـ pipeline والمعمارية |
| `docs/research/` | قرار المحرك، ملخص القياسات، والمراجع |
| `docs/runbooks/` | خطوات تشغيل حرفية: تجهيز بيئة، قياس، تدريب، رفع |
| `docs/history/` | سجل الجلسات بالتسلسل الزمني (إيش انعمل ومتى وبأي أمر) |
| `docs/postmortems/` | تحليل الحوادث (مثل تعليق السندبوكس) |
| `benchmark/data/` | `ground_truth.csv` + مستطيلات العداد/الشاشة/السطر + بصمات الصور |
| `benchmark/results/` | مخرجات كل محرك (JSON) + الأرقام المتحقق منها |
| `lab/` | كود البحث والتدريب (Python) + الأوزان + سجلات التدريب |
| `scripts/` | تنزيل النماذج، التحقق من الصور، فحص المستودع |

## تشغيل سريع
```bash
git clone https://github.com/moain2026/almaham-3.git && cd almaham-3
pip install -r requirements-lab.txt
bash scripts/download_models.sh                 # نماذج PP-OCR (SHA256 مثبّت)
# الصور الـ49 خاصة وغير موجودة في git — انظر docs/runbooks/setup-environment.md
export METER_PHOTOS_DIR=/path/to/photos && bash scripts/verify_photos.sh
bash scripts/check.sh                           # lint + إعادة إنتاج 15/46
```
