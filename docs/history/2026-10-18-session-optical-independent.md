## أوامر التنفيذ الرئيسية

من جذر المستودع:

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 PYTHONPATH=data/python:lab \
  python -m unittest discover -s lab -p test_optical_evidence.py -v
PYTHONPATH=data/python python -m ruff check \
  lab/optical_evidence.py lab/serial_identity.py \
  lab/bench_optical_evidence.py lab/test_optical_evidence.py
PYTHONPATH=data/python bash scripts/check.sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 PYTHONPATH=data/python:lab \
  python lab/bench_optical_evidence.py --barcode --peers \
  --out benchmark/results/engines/optical_evidence_2026-10-18.json
```

حزم اختيارية في `data/python`: zxing-cpp 2.3.0، pyflakes 3.4.0، ruff 0.14.1؛
NumPy 2.3.5 وOpenCV 4.11.0 مثبتتان مسبقًا. لا تغيير لrequirements-lab الخاصة بتدريب الوكلاء.
التجربة الثقيلة نُفذت في الخلفية بخيط OpenCV/BLAS واحد، ولم يبدأ خادم HTTP أو تدريب.
