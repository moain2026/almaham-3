## القرارات وأسبابها
1. **ثقة القارئ الحتمي = قاعدة اتفاق** (3 فحوص max/gray/green متفقة + طول ≥5 + ليس أول خانة غير صفرية) بدل هامش هندسي — لأن الهامش وحده أعطى 14/16 فقط عند ≥0.8، والقاعدة 56/57. **in-sample** ومكتوب ذلك في كل مكان.
2. **أوليّات Python مُعاد كتابتها بـ numpy خالص** (resize بصناديق صحيحة، closing بنافذة مقصوصة، Otsu بـ256 خانة، مكوّنات 8-اتصال، shear بأقرب جار، تباين صحيح) حتى يطابق Kotlin رقماً برقم — لهذا الزمن في Python ~400ms (لا يهم: المرجع للمطابقة؛ Kotlin هو المنتج).
3. **مثبّتات الاختبار بصيغة ARGB خام** لأن `javax.imageio` غير متاح في اختبارات وحدات Android، والقصوص مصغّرة لارتفاع 144 لتقليل حجم المستودع (1.2MB).
4. **digit_boxes يدوية بمدى + خطوة ثابتة** (لا تدريب عليها)؛ المائلة تقريبية.
5. **x86_64 في debug فقط** للمحاكي؛ release يبقى ARM.
6. **`synchronized(reader)` في demo** بدل تعديل `MeterReader` (ملك A) — الإصلاح الجذري اقتُرح لـ A.
