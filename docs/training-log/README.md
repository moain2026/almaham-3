# سجلّ التدريب والبحث — هيكلية التوثيق (طلب المالك 2026-10-21)

كل تجربة تدريب/بحث تُوثَّق في **مكان واحد قابل للبحث** حتى تُفيد أي تدريب مستقبلي بدقة.

| ماذا | أين |
|---|---|
| **كل تشغيل تدريب** (الأمر الحرفي، البيانات، الأوزان، الأرقام قبل/بعد على المجموعتين) | `docs/training-log/runs.md` (صف لكل تشغيل) + السجل الخام `lab/logs/train_*.log` + الأوزان في المستودع الخاص `weights_archive/` |
| **البحوث والاستشارات** (ماذا قرأنا، ماذا سأل الخبراء، ماذا قبلنا/رفضنا ولماذا) | `docs/research/*.md`، `docs/consult/*` (الملف + الإجابات الخام + القرار) |
| **المشاكل التي واجهناها وكيف أُصلحت** | `LESSONS.md` (جدول: التاريخ، المشكلة، الدرس) + `docs/training-log/issues.md` (تفصيل تقني) |
| **ملاحظات المالك الميدانية** (كل صورة + ملاحظته + تشخيصنا) | المستودع الخاص `webdemo/<date>/` (الصور + JSON) + `docs/research/field-webdemo-round*.md` (التحليل) |
| **محادثات المالك والقرارات** | `docs/training-log/owner-decisions.md` (التاريخ، القرار حرفياً، الأثر) |
| **الحالة الآن / الخطة** | `STATUS.md`، `docs/PLAN.md`، `CHANGELOG.md` |
| **الحقيقة الأرضية ومجموعات الاختبار** (لا تُدرَّب أبداً) | `benchmark/data/ground_truth.csv` (الـ49 v3)، `benchmark/data/erp/testset_human.csv` (+sha256 +siblings) |

قاعدة: **لا رقم بلا ملف نتائج** في `benchmark/results/engines/`، ولا تشغيل بلا صف في `runs.md`.
