# الالتقاط الذكي وقراءة العداد (تطبيق تجريبي)

## القصة
بصفتي قارئ عدادات في الميدان أريد أن أصوّر العداد بضغطة واحدة ويتعبّى الرقم تلقائياً حتى أخلص أسرع وبأخطاء أقل،
وتبقى صورة صغيرة دليلاً على القراءة.

## المتطلبات (صيغة EARS) — كل بند يشير لمصدره في البرومت
### الشاشات (§3، §4)
- REQ-001.1 — The app shall provide a «إدخال القراءة» screen with mock data: subscriber name, meter number, previous reading, current-reading field, meter-photo card, «حفظ والتالي». No ERP/login/server. (§3أ)
- REQ-001.2 — When «تصوير العداد» is pressed, the app shall open an in-app camera (not a system camera Intent) with a ready rectangle ≈78% of preview width, height/width ≈1.25, centred; outside dimmed; guide text «خلّ العداد كامل داخل المستطيل واضغط تصوير». (§4)
- REQ-001.3 — The rectangle shall be draggable and resizable from 4 corners + 4 edges with sane min/max, and the app shall remember its last position/size. (§4)
- REQ-001.4 — The camera shall support pinch zoom, 1×/2×/3× buttons, flash, close, tap-to-focus, and continuous autofocus. (§4)
- REQ-001.5 — When the shutter is pressed, the app shall capture immediately: **no** «جاري الالتقاط/انتظر» UI, **no** auto-capture waiting for stability/focus, **no** pre-capture validation. (§4، §8)

### الـ pipeline بعد الضغطة (§5) — كله في الذاكرة وعلى خيط خلفي
- REQ-001.6 — Capture with CameraX `CAPTURE_MODE_ZERO_SHUTTER_LAG` when `isZslSupported`, else `MINIMIZE_LATENCY`; compare with last `ImageAnalysis` frame and choose by measured numbers. (§5.1)
- REQ-001.7 — The app shall map the rectangle from screen to sensor-image coordinates accounting for `rotationDegrees`, PreviewView scale type, zoom and crop, and crop only that region. Unit tests for all orientations. (§5.2–3)
- REQ-001.8 — The saved photo shall be the crop, long side 1280px, WebP/JPEG q≈75–80, **80–200KB**, meter body + serial visible, basic EXIF (time, device), no location unless requested. Compression happens **after** the number is shown. The full frame is never written to disk. (§5.4، تحسينات السرعة)
- REQ-001.9 — The reader shall run on a small prepared copy: locate display, deskew/contrast/glare handling, read digits with per-digit confidence. (§5.5)
- REQ-001.10 — Cleaning: strip leading zeros (003155→3155), ignore small decimal digits, ignore model/serial/kWh text. (§5.6)
- REQ-001.11 — Logical validation after reading, never blocking save: (§5.7، §5.9)
  - If reading < previous → red. If consumption > configurable limit → orange.
  - If a digit has low confidence → colour that digit only.
  - If a digit has alternatives (e.g. 5/6) → pick the one giving plausible consumption vs previous.
  - If nothing read → field empty for manual entry.
- REQ-001.12 — The app shall return to the entry screen with the number + «قراءة تلقائية» badge, thumbnail in place of camera icon, button becomes «إعادة التصوير»; tapping the number edits it. (§5.8)
- REQ-001.13 — For every reading, log: engine value, saved value, edited?, confidence, per-stage timings, device model, source (camera/gallery). (§5.10، الشرح §4)
- REQ-001.14 — Model load + warm-up when the entry screen opens, not on shutter. (تحسينات السرعة)
- REQ-001.15 — Where «من الاستديو» is present, the photo shall be marked «من الاستديو». (الشرح §6)

### الاختبار الجماعي (§3د، §7)
- REQ-001.16 — A «اختبار جماعي» mode shall run the engine on the 49 photos in two modes (meter rectangle / full image) and report: exact match, per-digit accuracy, no-read rate, **confident-wrong** rate, per-stage time p50/p95/max, saved-photo size, failure table, device model.

### قيود عامة (§1، §6)
- REQ-001.17 — Fully offline. Code: one config file for all thresholds, no dead code, no TODOs, no copy-paste logic, pure functions with unit tests, zero linter warnings, portable to the main project.
- REQ-001.18 — The 49 photos are test-only; Copel-AMR/UFPR-AMR are research-only and shall not train a product model.

## معايير القبول (§8) — نجح أو ما نجح
- [ ] Shutter → number visible: **p50 < 300ms, p95 < 500ms** on a mid-range phone, model warm.
- [ ] Shutter captures instantly, no wait UI.
- [ ] Exact-match on human-readable photos **≥ 95%**; **confident-wrong < 1%**.
- [ ] Saved photo contains the full meter, **80–200KB**.
- [ ] Works fully offline.
- [ ] Unit tests for coordinate mapping, crop, cleaning, validation — all green.
- [ ] Zero linter warnings; architecture ready to port.
- لو ما وصلنا لرقم: نكتب الرقم الحقيقي والخطة، بدون تقريب.
