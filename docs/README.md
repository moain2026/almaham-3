# دليل التوثيق — almaham-3 (هيكلية ثابتة، بطلب المالك 2026-10-21)

كل شيء يُحفظ هنا بحيث يستطيع أي وكيل/مهندس في المستقبل أن يعرف **ماذا دُرِّب وكيف، ماذا بُحث، ماذا واجهنا وكيف أُصلح، وماذا قال المالك**.
القاعدة: لا رقم بلا ملف نتائج في `benchmark/results/`، ولا قرار بلا مستند هنا.

| المجلد | المحتوى | متى يُكتب |
|---|---|---|
| `training-log/` | **سجل كل تدريب**: الأمر الحرفي، البيانات (الشرائح وأعدادها بالنوع)، البذرة، الخطوات، الأوزان الناتجة، الأرقام قبل/بعد على المجموعتين (الـ49 و`testset_human`)، الاستنتاج | بعد كل تدريب (`docs/training-log/README.md` = الجدول الجامع) |
| `research/` | بحوث وتحليلات أسباب جذرية (كل ملف بتاريخ، بأرقام مقاسة ومراجع) | قبل أي تغيير معماري |
| `consultations/` | **استشارات النماذج/الخبراء**: الموجز المرسل (`brief-*.md`)، الأجوبة الخام (`answers-*/`)، جولة النقد (`critic-*.md`)، وقرارنا (`decision-*.md`: ما قبلناه وما رفضناه ولماذا) | عند كل استشارة |
| `owner-log/` | **محاضر كلام المالك**: ملاحظاته الميدانية من صفحة الويب، قراراته (X/B، الحقيقة الأرضية v3، تعريف الهدف)، وتصميمه للواجهة | عند كل جولة ملاحظات |
| `postmortems/` + `LESSONS.md` | ما انكسر وكيف أُصلح (بيئة، بيانات، كود) | عند كل عطل |
| `adr/` | قرارات معمارية مرقّمة | عند كل قرار بنيوي |
| `runbooks/` | كيف تُشغّل: البيئة، التدريب، النشر على Contabo، صفحة الويب | عند كل أداة جديدة |
| `handoff/` | تسليم بين الوكلاء | نهاية كل جلسة |
| `prompts/` | برومبتات الوكلاء (S/D/L) | عند تكليف وكيل |
| `history/` | سجل زمني للجلسات | يومياً |

الملفات الجذرية: `STATUS.md` (الحالة الآن، سطر مؤرَّخ لكل خطوة)، `CHANGELOG.md`، `LESSONS.md`، `docs/PLAN.md` (الخطة والأولويات)، `MODEL_CARD.md` (النموذج المشحون).
البيانات الخاصة (صور/أوزان/سجلات): مستودع `almaham-3-private-data` (ADR-0006) — `webdemo/<date>/` صور المالك الميدانية مع ملاحظاته.
